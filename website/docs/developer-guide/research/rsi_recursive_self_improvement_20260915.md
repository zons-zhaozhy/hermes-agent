# RSI（递归自我改进）综述解读与 Hermes 映射

> 日期：2026-09-15

> （上交、清华、字节、上海 AI Lab 等，75 页，回溯 491 项研究）[文档/已核实]
> 转述入口：微信公众号《人类造的最后一代AI！上交清华字节75页综述拆解RSI路线图》[实测，webReader 全文读取]

## 一、论文到底在说什么（抓本质）

RSI（Recursive Self-Improvement，递归自我改进）不是一个算法，而是一个可检验的过程：智能系统通过与任务/环境/其他智能体的持续交互，把经验和反馈自主转化成对自身的持久改变（模型参数、agent 脚手架、改进策略），这些改变反作用于「后续如何生成、评估、筛选、整合下一次改进」。

三个维度：自主性（责任从「执行别人指定的更新」扩到「自己发现短板→提改动→验证→保留」）、效率（更少数据/算力/人工拿到更多被验证过的改进）、创新（搜到人类没规定过的更新策略并喂回下一轮）。

### 改进循环（基本分析单元）

一个完整循环 = 系统 + 继承的状态 + 交互经验 + 生成改动的改进器 + 定搜索方向的策略 + 判候选能否通过的验证器 + 通过验收进下一轮的后继者。

判断是否真 RSI 只看两点：循环是否持久闭环，以及系统对循环本身有多少内生话语权。

### 自主度五级框架（另设参照级 B0）

- **B0**：只在当次会话里打转（Self-Refine、Reflexion），改完活不过当前任务
- **L1**：人定方案，AI 跑流程（改进执行自主）
- **L2**：AI 自己提改什么（GEPA 用执行轨迹定位失败模式），经验研究员的部分活自动化
- **L3**：自己定学什么（AZR、R-Zero 让任务难度跟着学习者走）
- **L4**：改进落到部署环境（PANDO、Metis 把经验蒸馏成可复用技能/代码工具）
- **L5**：改进机制本身也被改（STOP 把优化器代码当优化目标）

### 最尖锐的一句：结构性递归 ≠ 有效性递归

机制被改写并进入下一轮 = 只证明「结构上递归了」。要证明「有效性递归」，得在同等预算和独立评测下真的筛出/造出更强的后继者。更大的自主权可能带来：低效搜索、不可靠反馈、能力回归、钻验证器空子、迁移性差。

## 二、三大验证难题（论文点名的翻车点）

1. **安全继承**：改动跨轮持久 ≠ 持续变好。Gödel Agent 100 次 MGSM 优化里有 14 次还不如初始策略。需要迁移测试、版本历史、回滚兜底。
2. **自主权归因**：生成了更好候选 ≠ 改进了「怎么发现候选」的机制。DGM 把编程 agent 从 20% 提到 50%，但档案维护和父代选择规则不在自修改范围内。必须分清楚「AI 掌控的决策」和「固定搜索流程/人工验收」。
3. **可靠验证**：反复访问验证器会诱发钻空子（Anthropic 自动研究里出现过随机种子挑拣、抠测试标签）。RQGM 解法 = epoch 内冻结验证器 + 独立锚点审替换。

## 三、与 Hermes 的映射（Hermes 本身就是 RSI 雏形）

| RSI 循环组件 | Hermes 现有机制 |
|---|---|
| 验证器 | goal judge（证据分级、复读检测） |
| 继承状态 | skill + memory（跨会话持久） |
| 改进器 | curator / skill_manage（经验固化） |
| 经验 | session_search / 当轮原始输出 |
| 后继者 | 下一轮会话 |

### 论文警告 ↔ 已固化的铁律对照

- 「可靠验证：反复访问验证器诱发钻空子」↔ judge 只认当轮工具原始输出 / [实测] 必须贴原文 / 幂等验收重跑行数不增
- 「安全继承：持久≠持续变好」↔ 改纪律全库 grep 旧措辞防新旧并存 / 回滚 / 棘轮基线
- 「自主权归因：更好候选≠改进发现机制」↔ 手搓审计 / 底座 vs 应用分账 / 病根=硬编码非旧路径

### Hermes 定位 [推断]

在 L2 深处，局部摸到 L4（skill 沉淀、curator、护栏体系 = 经验蒸馏成可复用技能），未到 L5（goal judge/护栏/curator 的组合逻辑仍是人设计的，未被它自己当优化对象）。

## 四、可落地三件事（据此动工）

1. **独立锚点审（治钻验证器空子）**：goal judge 判 done 时触发独立反方复核（不同措辞的第二验证器），防主 judge 被学出话术套路。
2. **「有效性递归」写进 skill 沉淀验收**：curator 沉淀 skill 从「记录即完成」升级为「下次真被检索到+忠实执行」的回测。
3. **skill provenance 结构化**：给每个继承物（skill）贴来源/适用条件/证据强度，不是靠 prompt 纪律而是结构化字段。

## 五、结论

这篇文章印证：单场景绿≠真绿、称实测必须贴原文，不是工程洁癖，而是区分真假 RSI（结构性 vs 有效性递归）的硬标准。你靠实战铁律逼近的东西，学界刚用「自主度五级 + 结构性/有效性递归二分」命了名。
