# AI 陪伴+成长 技术方案骨架（v0.1 草稿）

日期：2026-09-08 ｜ 状态：骨架草稿，待反方审查清单合并修订
前置调研：docs/research/ai_games_panorama_20260908.md（全景+合规红线）

## 一、产品定义（假设，可逆）

- 一句话：用户拥有一个长期陪伴角色，角色有稳定人格、可成长的关系与能力，
  跨会话记忆构成核心体验；「拿掉 LLM 玩法即崩」= AI-native 判据满足。
- 「成长」双轴 [假设]：
  a) 角色成长：人格状态机演进（信任等级/关系里程碑/技能解锁，Voyager 式
     可增长技能库映射到陪伴角色的能力成长）。
  b) 用户成长：目标陪伴（学习/习惯/情绪），角色作为过程见证者与推动者。

## 二、分层架构（v0.1）

```
L1 交互层     文本/语音输入 → 安全过滤 → 意图&情感识别
L2 人格层     人格向量(CN121659983A式) + 人格状态机(信任/关系阶段)
              + 表达风格约束（决定「谁在说话」）
L3 记忆层     核心壁垒：分层记忆（工作记忆/情景记忆/语义记忆/关系图谱）
              参考谱系：Generative Agents Memory Stream(recency/importance/
              relevance 检索打分+Reflection) → SGMem/OmniMem 工程化版
L4 成长引擎   里程碑触发器 + 技能库(可执行能力) + 反思升华(离线批处理)
L5 合规护栏层 未成年人识别+模式切换 / 情感操纵检测(禁诱导变现话术) /
              内容安全 / 拟人化服务备案接口 —— 前置设计非后补 [硬约束]
L6 底座       LLM 路由(分级:闲聊小模型/关键节点大模型) + 成本护栏
```

关键设计纪律 [文档，全景报告结论]：LLM 只做内容提案者，确定性引擎收口——
记忆写入/检索、状态迁移、里程碑判定全部走确定性代码，LLM 不直接改状态。

## 三、与既有底座的关系（假设，待反方审查验证）

- 复用：LLM 网关/路由（Cortex 思路）、护栏框架（OntoX 护栏取向）、
  skill 体系（角色技能库类比）、记忆分域存储（PG 全家族铁律）。
- 不复用/自建：人格状态机、关系图谱记忆模型、成长里程碑 DSL。

## 四、反方审查（2026-09-08 10:23 独立子代理完成，6 轮独立检索核实）

结论：不建议按现口径立项。用户同向判断（10:25）：「陪伴成长这个方向不太好搞」。

【技术硬伤】
- T1[高] 长程一致性是学术界公认未解难题，恰是本方案核心卖点。ACL 2026
  Findings（Memory-Driven Role-Playing）：长程开放式对话维持一致人设是首要
  失败点，context/role drift + knowledge attrition 是系统性失效模式。
  「长期成长」前提是「长期不崩」，后者无工程保证。
- T2[高] 记忆架构无收敛答案且是大厂壁垒（SGMem/OmniMem/M3-Agent 互不兼容），
  自研=用最弱资源打别人主战场。
- T3[中] 斯坦福小镇论文自述：25 agent 模拟两天成本数千美元+数天墙钟；
  陪伴要求每用户 7x24 常驻推理，成本随用户线性放大而行业付费转化不及预期。

【商业风险】
- B1[高] 付费意愿证据链断裂：「逆水寒 3 天 500 万」是玩家创建 NPC 数
  （2024-08 官方宣发口径），非留存/付费/陪伴时长，且依托亿级 MMO 用户盘与
  伏羲平台，不可迁移；Simile 投的是 B 端模拟器，Inworld 是 B2B 中间件——
  三个标杆无一证明 C 端陪伴付费成立。
- B2[高] 行业面：AI 社交下载量暴跌八成（新浪财经 2025-07），角色语言重复、
  忘记对话、同质化、付费转化不及预期是行业性痛点。

【合规红线】
- C1[高] 未成年人识别是强制项但技术不成熟：实名/人脸体验损伤大且可绕过，
  一起未成年人情感依赖舆情即可能整体下架。识别方案（含绕过对抗评估）必须
  先于玩法开发落地并过法务评审。
- C2[中] Character.AI 2025-10 起禁止未成年人交互+加州 SB 243——全球监管
  同向收紧，立法趋势未止。

【裁决】方向判定为不立项（C 端陪伴产品口径）。已投入的调研资产（记忆/
人格架构谱系、合规红线清单）保留，可服务于其他方向（如 B 端拟人化交互
中间件、行业陪练/培训场景——避开 C 端情感依赖雷区，详见
b2b_ai_roleplay_training_20260908.md）。

【反方完整版补充数据（subagent-summary-0-20260908_102309 全文核对新增）】
- 市场崩塌明细 [文档，新浪财经/DataEye 2025-07]：星野月下载 486万→93万、
  猫箱 264万→61万（2025 年 1→5 月苹果端）；三日新增留存<20%；单角色平均
  建联时长仅 5-7 天；某字节前高管 AI 社交项目约 3 亿美元融资后解散。
- 出海退路同样封死 [文档]：Character.AI 禁 18 岁以下开放式聊天、Garcia 案
  产品责任索赔被受理、FTC 质询 7 家、加州 SB 243 生效、澳洲 eSafety 法律通知。
- 北极星指标与合规互斥：产品指标（时长/依赖深度）恰是新规打击对象
  （防沉迷/防依赖），KPI 结构性冲突。
- 底座范式冲突（若当年强行做）：人格状态须外置独立状态服务（DB 事实源），
  严禁塞进系统提示词——与 Hermes prompt 缓存不可破纪律的边界说明。
- 反方给出的可迁移止损纪律（适用一切新方向预研）：①灰度留存数据达标才进
  开发；②单用户日成本<日收入的纸面证明+端到端延迟实测；③无量化评测基线
  不谈架构。
