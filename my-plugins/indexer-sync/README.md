# Indexer-Sync Plugin

This is a snapshot of the `indexer-sync` plugin that lives in
`~/.hermes/plugins/indexer-sync/`. Copy these files there to activate:

```bash
cp my-plugins/indexer-sync/__init__.py my-plugins/indexer-sync/plugin.yaml ~/.hermes/plugins/indexer-sync/
```

Then add `indexer-sync` to `plugins.enabled` in `~/.hermes/config.yaml`.
